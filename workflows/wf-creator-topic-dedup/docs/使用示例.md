# 使用示例

技能：**选题查重**（`wf-creator-topic-dedup`）

> ⚠️ **本技能的真实效果示例尚未补齐**：以下仅为输入 / 输出契约（**不构成效果证据**）与平台兼容性验证结果。发布前须补至少 3 组「真实输入 → 实际产出」。

---

## 示例一 · 标准用法（真实运行）

```bash
python3 ../../tools/kb_manage.py --db examples/input/kb.json add --title '通勤保温杯实测' --tags '产品,测评' --weight 3
python3 ../../tools/kb_manage.py --db examples/input/kb.json add --title '办公室喝热水指南' --tags '场景,科普' --weight 2
python3 ../../tools/kb_manage.py --db examples/input/kb.json add --title '保温原理 3 秒讲清' --tags '科普' --weight 1
python3 ../../tools/kb_manage.py --db examples/input/kb.json list --top 5
```

**真实输出**：

```console
已存在同名条目：通勤保温杯实测（用 update 修改）
已存在同名条目：办公室喝热水指南（用 update 修改）
已存在同名条目：保温原理 3 秒讲清（用 update 修改）
[权重3] 通勤保温杯实测  #产品,测评  用过0次
[权重2] 办公室喝热水指南  #场景,科普  用过0次
[权重1] 保温原理 3 秒讲清  #科普  用过0次

共 3 / 3 条
```

> 选题库落盘为 JSON，可增删改查与导出，权重即复用热度

> **注意**：选题库会**膨胀**：定期用 weight 排序淘汰长期低权重的僵尸选题。

---

## 示例二 · 用你自己的材料

```bash
python3 ../../tools/kb_manage.py --db /path/to/your-data/kb.json add --title '通勤保温杯实测' --tags '产品,测评' --weight 3
```

把 `examples/input/` 下的文件换成你的真实材料即可；**输入结构不要改**，改了字段名脚本会读不到。

---

## 示例三 · 嵌进自动化链路

```bash
set -e
python3 ../../tools/kb_manage.py --db examples/input/kb.json add --title '通勤保温杯实测' --tags '产品,测评' --weight 3 || exit 2   # 非零即阻断
```

脚本是纯函数：文件/stdin 进、stdout 出、退出码表达判定，因此可以被 CI、定时任务或上层工作流直接编排。
