# 竞品内容监控 · 架构与流程图

## 本技能的四层结构

```mermaid
flowchart TB
  U["使用层：爆款选题策划师 的使用者"]
  T["触发层：竞品内容监控"]
  X["执行层：5 个步骤"]
  O["产出层：更新摘要+互动数据"]
  U --> T --> X --> O
```

| 层 | 内容 |
|---|---|
| 使用层 | 全体内容创作者（5000 万+，据 R2 调研），尤其日更压力的短视频/图文作者；员工定位：每天早会前 5 分钟交付"今日选题包"的选题合伙人 |
| 触发层 | 关键词 / 显式点名「竞品内容监控」；触发方式：用户提出需求 |
| 执行层 | **接收输入**：确认拿到的是「竞品账号列表」，先做完整性检查。 → **跟踪指定竞品账号更新并摘要**：按该定义执行，并把用到的输入项显式写进产出。 → **交叉校验**：把本步结论与上一步结论对一遍，出现矛盾先解决矛盾再往下走。 → **落盘产出**：按「输出契约」四要素定稿，缺数据的写 `<待填>`。 → **回指自检**：逐个数字回指输入来源，回指不上的删掉。 |
| 产出层 | 更新摘要+互动数据 |
